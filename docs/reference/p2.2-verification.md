## Interpretation

`NO_VERIFICADO` is intentional. Static adapter coverage proves command shape
and result classification; it does not prove that a model loaded the prompt or
that MCP completed. A future run may promote a runtime only when it includes a
final foreground transcript containing the expected Gentle-AI authority
evidence and a clean bounded exit.
